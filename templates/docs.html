PayHub API Documentation

Bot .env e shudhu 3 ta jinish thakbe:

PAYMENT_BASE_URL={{ base }}
PAYMENT_API_KEY=pk_live_xxxx
PAYMENT_WEBHOOK_SECRET=whsec_xxxx

1. Payment flow

  1. Customer bot e amount dey
  2. Bot POST /api/v1/invoice call kore
  3. Bot UID + amount dekhaay
  4. Customer Binance theke UID te pay kore TX/Order ID dey
  5. Bot POST /api/v1/verify call kore
  6. PayHub Binance API diye check kore
  7. PAID hole bot webhook paye + nijer DB te balance add kore

2. Create invoice

POST {{ base }}/api/v1/invoice

5. Bot code example

import aiohttp, os
BASE=os.getenv("PAYMENT_BASE_URL")
KEY=os.getenv("PAYMENT_API_KEY")

async def create_invoice(uid, amount):
    async with aiohttp.ClientSession() as s:
        r = await s.post(f"{BASE}/api/v1/invoice",
            headers={"X-API-Key": KEY},
            json={"telegram_id": str(uid), "amount": str(amount)})
        return await r.json()

async def verify(invoice_id, txid):
    async with aiohttp.ClientSession() as s:
        r = await s.post(f"{BASE}/api/v1/verify",
            headers={"X-API-Key": KEY},
            json={"invoice_id": invoice_id, "txid": txid})
        return await r.json()
